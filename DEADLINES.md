# Сроки сдачи

Это единственный файл репозитория, в котором публикуются актуальные сроки сдачи заданий и правила штрафов. Даты из ноутбуков семинаров использовать не следует.

## Задания к семинару один:
  * найти два отсутствующих числа
    * 10е сентября пара включительно без штрафов
    * 15е сентября пара включительно штраф 50%

Бонусная задача найти три уникальных числа 
  * 1е октября без штрафов, далее не принимается
